ROZOOM User Manual Інструкція користувача ROZOOM

1. Install 1. Встановлення

Download the installer for your OS from the latest release. Завантажте інсталятор для своєї ОС зі сторінки останнього релізу.

Each platform has two variants — slim (smaller download, pulls in CLI tools like kubectl on first use) and full-offline (everything bundled, no network needed after download); pick slim unless you need to work offline. Для кожної платформи є два варіанти — slim (менший файл, підтягує CLI-інструменти типу kubectl при першому використанні) і full-offline (усе вже всередині, мережа після завантаження не потрібна); обирайте slim, якщо не потрібна офлайн-робота.

Linux

ROZOOM ships as .deb and .rpm packages. ROZOOM постачається у форматах .deb і .rpm.

  • .deb (Ubuntu, Debian, and derivatives): download the file, then either double-click it in your file manager, or run:
    sudo apt install ./ROZOOM_K8s_Linter_IDE_<version>_amd64_slim.deb     .deb (Ubuntu, Debian та похідні): завантажте файл, потім двічі клацніть на нього у файловому менеджері, або виконайте в терміналі:
    sudo apt install ./ROZOOM_K8s_Linter_IDE_<версія>_amd64_slim.deb
  • .rpm (Fedora, openSUSE, and derivatives): download the file, then run:
    sudo dnf install ./ROZOOM_K8s_Linter_IDE-<version>-1.x86_64_slim.rpm
    (on openSUSE: sudo zypper install ./ROZOOM_K8s_Linter_IDE-<version>-1.x86_64_slim.rpm)     .rpm (Fedora, openSUSE та похідні): завантажте файл, потім виконайте:
    sudo dnf install ./ROZOOM_K8s_Linter_IDE-<версія>-1.x86_64_slim.rpm
    (на openSUSE: sudo zypper install ./ROZOOM_K8s_Linter_IDE-<версія>-1.x86_64_slim.rpm)

(swap slim for full-offline in the filename if you picked that variant) (замініть slim на full-offline у назві файлу, якщо обрали цей варіант)

Windows

Download the .exe or .msi installer and run it. Завантажте інсталятор .exe або .msi і запустіть його.

macOS

Download the .dmg (Apple Silicon / aarch64 only — no Intel build yet), open it, and drag ROZOOM to Applications. Завантажте .dmg (лише Apple Silicon / aarch64 — збірки для Intel ще немає), відкрийте його і перетягніть ROZOOM у Applications.

Launch ROZOOM from your applications menu (or Start menu / Launchpad) once installed. Після встановлення запустіть ROZOOM з меню застосунків (або зі Start menu / Launchpad).

2. Connect a cluster 2. Підключення кластера

The first screen after install is Manage Kubernetes Clusters. ROZOOM doesn't create clusters — it only connects to ones you already have. Three ways in: Перший екран після встановлення — Manage Kubernetes Clusters. ROZOOM не створює кластери — лише підключається до вже наявних. Три способи:

  • Upload a kubeconfig file Завантажити файл kubeconfig
  • Paste kubeconfig YAML directly Вставити YAML kubeconfig напряму
  • Let ROZOOM scan standard locations (~/.kube/config, $KUBECONFIG, cloud CLIs) — matches show up under "Detected kubeconfig files" Дати ROZOOM просканувати стандартні місця (~/.kube/config, $KUBECONFIG, хмарні CLI) — знайдені збіги з'являються у списку "Detected kubeconfig files"

Nothing connects automatically. Every detected or pasted config needs a confirmation click before ROZOOM touches it. Нічого не підключається автоматично. Кожен знайдений чи вставлений конфіг потребує підтвердження кліком, перш ніж ROZOOM його використає.

3. Linter — on by default 3. Лінтер — увімкнений за замовчуванням

Once a cluster is connected, ROZOOM runs a health check immediately — nothing to turn on. Results show up on the cluster's card as Critical, Warning, or OK, broken down by Health, Capacity, HA, and Security. Одразу після підключення кластера ROZOOM сам запускає перевірку — нічого не потрібно вмикати. Результат з'являється на картці кластера: Critical, Warning або OK, з розбивкою по Health, Capacity, HA та Security.

You can turn the linter off two ways: Вимкнути лінтер можна двома способами:

  • Per cluster — click the gauge icon on that cluster's card. Для одного кластера — клацніть на іконку-гейдж на картці цього кластера.
  • For everything — use the toggle in the dashboard's top toolbar. Для всіх кластерів одразу — тогл у верхній панелі дашборду.

When it's off, the cluster shows a "Paused" badge and a banner reminding you diagnostics won't run until you turn it back on. Коли лінтер вимкнено, на картці з'являється позначка "Paused" і банер із нагадуванням, що діагностика не запускатиметься, доки ви не увімкнете його знову.

4. Telemetry 4. Телеметрія

The first time a scan finishes, ROZOOM shows a banner asking whether you want to share anonymous usage data — it only asks after you've actually seen the app do something, not before. Nothing is sent before you answer, not even the fact that you added a cluster. Choose "No thanks" and nothing leaves your machine. You can change this later in Fleet Settings. Коли перше сканування завершиться, ROZOOM покаже банер із питанням, чи хочете ви поділитися анонімними даними про використання — питання з'являється лише після того, як ви побачили застосунок у дії, а не до того. До вашої відповіді нічого не надсилається, навіть факт додавання кластера. Оберіть "No thanks" — і з вашого пристрою нічого не піде. Змінити це рішення пізніше можна у Fleet Settings.
