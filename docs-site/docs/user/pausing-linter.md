# Linter — on by default

Once a cluster is connected, ROZOOM runs a health check immediately — nothing to turn on. Results show up on the cluster's card as **Critical**, **Warning**, or **OK**, broken down by Health, Capacity, HA, and Security.

You can turn the linter off two ways:

- **Per cluster** — click the gauge icon on that cluster's card.
- **For everything** — use the toggle in the dashboard's top toolbar.

When it's off, the cluster shows a **Paused** badge and a banner reminding you diagnostics won't run until you turn it back on.
