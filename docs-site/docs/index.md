# ROZOOM Documentation

ROZOOM is an open source Kubernetes manager: a desktop app that connects to clusters you already have and shows their health without the kubectl friction.

## User guide

- [Install ROZOOM](/user/quickstart/) — packages for Linux, Windows, and macOS, slim and full-offline variants.
- [Connect your first cluster](/user/connect-cluster/) — kubeconfig upload, paste, or auto-detection.
- [Pausing the linter](/user/pausing-linter/) — health checks run by default; here is how to pause them.
- [Telemetry & privacy](/user/telemetry-privacy/) — what is shared, when, and how to say no.

Looking for the source? ROZOOM is developed in the open at [github.com/ceh13-community/rozoom](https://github.com/ceh13-community/rozoom).
