# Документація ROZOOM

ROZOOM — відкритий Kubernetes-менеджер: десктопний застосунок, що підключається до ваших наявних кластерів і показує їхнє здоров'я без тертя kubectl.

## Посібник користувача

- [Встановлення ROZOOM](/user/quickstart/) — пакети для Linux, Windows і macOS, варіанти slim та full-offline.
- [Підключення першого кластера](/user/connect-cluster/) — завантаження kubeconfig, вставка YAML або автовиявлення.
- [Призупинення лінтера](/user/pausing-linter/) — перевірки здоров'я запускаються за замовчуванням; як їх призупинити.
- [Телеметрія та приватність](/user/telemetry-privacy/) — що надсилається, коли і як відмовитись.

Шукаєте код? ROZOOM розробляється відкрито: [github.com/ceh13-community/rozoom](https://github.com/ceh13-community/rozoom).
