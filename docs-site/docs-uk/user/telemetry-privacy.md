# Телеметрія та приватність

Коли перше сканування завершиться, ROZOOM покаже банер із питанням, чи хочете ви поділитися анонімними даними про використання — питання з'являється лише після того, як ви побачили застосунок у дії, а не до того.

До вашої відповіді нічого не надсилається, навіть факт додавання кластера. Оберіть **No thanks** — і з вашого пристрою нічого не піде.

Змінити це рішення пізніше можна у **Fleet Settings**.
