# Лінтер — увімкнений за замовчуванням

Одразу після підключення кластера ROZOOM сам запускає перевірку — нічого не потрібно вмикати. Результат з'являється на картці кластера: **Critical**, **Warning** або **OK**, з розбивкою по Health, Capacity, HA та Security.

Вимкнути лінтер можна двома способами:

- **Для одного кластера** — клацніть на іконку-гейдж на картці цього кластера.
- **Для всіх кластерів одразу** — тогл у верхній панелі дашборду.

Коли лінтер вимкнено, на картці з'являється позначка **Paused** і банер із нагадуванням, що діагностика не запускатиметься, доки ви не увімкнете його знову.
